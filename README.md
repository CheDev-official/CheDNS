## 🌐 CheDNS v1.2b — авторизация, HTTPS, импорт блок-листов

Первый релиз с **авторизацией** и **HTTPS**. Что нового по сравнению с v1.1:

- 🔒 **Авторизация в панели** — логин и пароль
- 🌐 **HTTPS** с самоподписанным сертификатом
- 📥 **Импорт блок-листов** — вставка списка или загрузка файла
- 🌐 **Wildcard-записи** — `*.example.local → IP`
- 💾 **Экспорт/импорт конфига** — кнопки в панели
- 📝 **Логи в файл** с ротацией (5 МБ × 5)
- 🛡️ **CheProtect** — баннер-предупреждение, если стоит пароль по умолчанию

---

## 🚀 Как запустить

1. Скачайте `CheDNS.exe` из вложений ниже
2. Запустите **от имени администратора** (правой кнопкой → «Запуск от имени администратора»)
3. Разрешите доступ в брандмауэре (частные сети)
4. Откройте `https://127.0.0.1:8080`
   - Браузер предупредит о самоподписанном сертификате → **«Дополнительно»** → **«Перейти на сайт»**
   - Если HTTPS не работает — откройте `http://127.0.0.1:8080`
5. Войдите: **`admin`** / **`admin`**
6. **Сразу смените пароль!**

Файл `chedns_config.json` создастся автоматически рядом с exe.

## ⚠️ Известная проблема

В **собранном exe** HTTPS может не запускаться из-за особенностей упаковки библиотеки `cryptography` в PyInstaller. Сервер продолжает работать по **HTTP** на том же порту — функциональность полностью сохраняется.

**Если нужен HTTPS прямо сейчас:** скачайте исходник, установите зависимости и запустите `python chedns.py` — HTTPS работает из исходников.

Исправление в exe — в следующей версии.

## 📦 Установка зависимостей (для запуска из исходников)

**Требования:** Python 3.10+ (Windows x64)

**Одной командой:**
```
pip install dnslib flask cryptography pyinstaller
```

**Если pip не работает — через `python -m`:**
```
python -m pip install dnslib flask cryptography pyinstaller
```

> `pyinstaller` нужен **только** для сборки exe. Для запуска из исходников достаточно первых трёх пакетов.

**С фиксированными версиями:**
```
pip install dnslib==0.9.26 flask==3.1.3 cryptography>=42.0.0 pyinstaller>=6.15
```

**Запуск из исходников:**
```
python chedns.py
```

**Сборка exe:**
```
build.bat
```
